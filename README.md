**سقفینو** یک پلتفرم فارسی و راست‌به‌چپ برای جست‌وجوی املاک و مستغلات است که با Next.js App Router، React 19 و Tailwind CSS 4 توسعه داده می‌شود.

طراحی رابط کاربری بر پایه فایل‌های Figma و با تمرکز بر تجربه موبایل، انیمیشن‌های نرم و دسترس‌پذیری انجام شده است.

## درباره پروژه

سقفینو دو تجربه مستقل دارد:

- **صفحه مهمان:** معرفی خدمات، دسته‌بندی املاک، مشاورین و مجله سقفینو
- **صفحه کاربر واردشده (Home Pro):** آگهی‌های اجاره، خدمات، جست‌وجوهای پیشنهادی، املاک برتر و مشاورین برتر تهران

علاوه بر این، مسیر **`/rent`** فهرست کامل آگهی‌های اجاره را با فیلترهای پویا، نقشهٔ تعاملی و صفحه‌بندی نمایش می‌دهد و مسیر **`/properties/[id]`** جزئیات هر آگهی را در دسترس قرار می‌دهد.

ورود در حال حاضر به صورت **دمو** پیاده‌سازی شده و شامل دریافت شماره موبایل و کد تأیید است. شماره و کد دمو در `lib/auth.js` قرار دارند و کد تأیید عمداً در رابط کاربری نمایش داده نمی‌شود.

## ویژگی‌ها

- طراحی کامل **RTL** با فونت شبنم (Shabnam FD)
- رابط کاربری واکنش‌گرا برای موبایل، تبلت و دسکتاپ
- هدر شناور با مخفی‌شدن هوشمند هنگام اسکرول و منوی موبایل
- ورود دومرحله‌ای دمو (شماره موبایل + کد تأیید) همراه با اعتبارسنجی
- سیستم توست سفارشی با انیمیشن Motion
- صفحه مهمان با بخش‌های Hero، راهنما، دسته‌بندی املاک، مشاورین و بلاگ
- صفحه Home Pro با بخش‌های Hero، آگهی‌های اجاره، خدمات، جست‌وجوهای پیشنهادی، املاک برتر و مشاورین برتر
- کاروسل اسکرولی با Snap در موبایل و گرید چندستونه در دسکتاپ
- **صفحه آگهی‌های اجاره (`/rent`)** با فیلترهای پویا بر اساس ۳۱ استان و ۱٬۴۸۱ شهر ایران
- فیلتر نوع ملک، تعداد اتاق، متراژ، اجاره، رهن و امکانات؛ مرتب‌سازی و صفحه‌بندی با URL
- **نقشهٔ تعاملی Leaflet** با پین قیمت آگهی‌ها، پاپ‌آپ و نمای سراسری ایران؛ کشورهای همسایه با ماسک جغرافیایی پوشانده می‌شوند
- کارت‌های آگهی هم‌طراحی کارت‌های Home Pro (تصویر، زمان انتشار، عنوان، آدرس، رهن و اجاره)
- کارت دفاتر املاک در میان نتایج، لینک‌های جست‌وجوی مرتبط و حالت «بدون نتیجه»
- نسخهٔ تمام‌صفحهٔ نقشه در موبایل
- **صفحه جزئیات آگهی (`/properties/[id]`)** با گالری موزاییکی تصاویر در بالای صفحه، پیمایش انیمیشنی و نمایش تمام‌صفحه، مشخصات کامل و جزئیات ریز، امکانات، نقشه، تماس با دفتر و آگهی‌های مشابه
- **پاپ‌آپ اطلاعات آژانس** با انیمیشن GSAP، باز شدن از محل کارت، بستن با Escape، قفل اسکرول و مدیریت فوکوس
- انیمیشن‌های ورود بخش‌ها با GSAP و ScrollTrigger
- پشتیبانی از `prefers-reduced-motion`
- پایه اتصال به MongoDB و مدل‌های آماده برای توسعه APIها

## نصب و راه‌اندازی

### پیش‌نیازها

- **Node.js** نسخه `20.9` یا بالاتر
- **npm** (یا pnpm/yarn)
- **MongoDB** به صورت لوکال یا MongoDB Atlas

### مراحل اجرا

```bash
# 1. دریافت سورس
git clone https://github.com/ehsandev2008/sagfino.git
cd sagfino

# 2. نصب وابستگی‌ها
npm install
```

فایل `.env.local` را در ریشه پروژه بسازید:

```env
MONGODB_URI=mongodb://localhost:27017/sagfino
```

در صورت استفاده از Atlas، رشته اتصال اختصاصی خود را جایگزین کنید.

```bash
# 3. اجرای محیط توسعه
npm run dev
```

سایت در آدرس [http://localhost:3000](http://localhost:3000) در دسترس خواهد بود.

### داده‌های نمونه

برای مشاهدهٔ فهرست کامل ۱۶۸ آگهی اجاره و ۳۱ دفتر املاک، دیتابیس را یک‌بار seed کنید:

```bash
npm run seed:listings
```

این اسکریپت مجموعه‌های `properties` و `agencies` را در دیتابیس `sagfino` می‌سازد. اگر MongoDB در دسترس نباشد، صفحه‌های `/rent` و `/properties/[id]` به‌صورت خودکار از داده‌های نمایشی داخلی (`lib/listings/demo.js`) استفاده می‌کنند.

> برای مشاهده Home Pro کافی است از دکمه «ورود» در هدر استفاده کنید. اطلاعات ورود دمو در `lib/auth.js` تعریف شده است.

### اسکریپت‌ها

| دستور | توضیح |
|---|---|
| `npm run dev` | اجرای محیط توسعه با Turbopack |
| `npm run build` | ساخت نسخه Production |
| `npm run start` | اجرای نسخه Production |
| `npm run lint` | بررسی کدها با ESLint |
| `npm run seed:listings` | درج آگهی‌ها و دفاتر املاک نمونه در MongoDB |

### صفحه اجاره (`/rent`)

- فیلترها بر اساس پارامترهای URL اعمال می‌شوند و با هر تغییر، نشانی صفحه به‌روزرسانی می‌شود.
- شهر و استان از API محلی خوانده می‌شوند: ۳۱ استان و ۱٬۴۸۱ شهر.
- نتایج شامل کارت آگهی، کارت دفتر املاک، نقشهٔ تعاملی و صفحه‌بندی است.
- نقشه با فیلتر شهر جابه‌جا نمی‌شود و نمای سراسری ایران را حفظ می‌کند؛ یک ماسک GeoJSON فقط خاک ایران را نشان می‌دهد و کشورهای همسایه پوشانده می‌شوند.
- در موبایل نقشه به‌صورت تمام‌صفحه باز می‌شود.
- در صورت خالی بودن نتیجه، حالت اختصاصی «ملک با مشخصات مورد نظر پیدا نشد» با تصویر و دکمهٔ بازگشت به صفحه اصلی نمایش داده می‌شود.
- نقشه و نوار مرتب‌سازی در حالت بدون نتیجه پنهان می‌شوند تا تمرکز روی راهنمای بازگشت باقی بماند.

### صفحه جزئیات آگهی (`/properties/[id]`)

- گالری موزاییکی تصاویر در بالای صفحه (بدون نوار مسیر و بلوک عنوان بالای گالری)
- پیمایش تصاویر با دکمه‌های قبلی/بعدی و انیمیشن اسلاید، سوایپ در موبایل و گالری تمام‌صفحه با کلیدهای جهت‌دار
- چیدمان دوستونی ۶۰/۴۰: جزئیات آگهی در ستون راست (۶۰٪) و کارت شناور انتشاردهنده در ستون چپ (۴۰٪)
- کارت انتشاردهنده شامل لوگو و نام دفتر، تصویر و نام مشاور، امتیاز، تعداد آگهی فعال و دکمهٔ «اطلاعات تماس» است
- کارت انتشاردهنده در دسکتاپ زیر هدر شناور می‌ماند و در موبایل زیر جزئیات آگهی قرار می‌گیرد
- سربرگ جزئیات شامل دسته‌بندی و شهر آگهی در راست و دکمه‌های اشتراک‌گذاری و نشان کردن در چپ
- گرید سه‌ستونهٔ مشخصات سریع (متراژ، اتاق، طبقه) و ردیف‌های ودیعه و اجارهٔ ماهیانه
- ساعت بازدید و گزارش تخلف آگهی
- امکانات دوستونه (پارکینگ، انباری، آسانسور، جنس کف، سرویس بهداشتی، سرمایش و گرمایش)
- توضیحات آگهی همراه با سن بنا، موقعیت جغرافیایی، نوع سند، امکانات تفریحی، سایر امکانات و زمان بازدید
- نقشهٔ موقعیت ملک با نمای فشرده
- نوار پایانی آمار (زمان ثبت، بازدید و وضعیت) و بازخورد مفید بودن آگهی
- باز شدن پاپ‌آپ «اطلاعات تماس» با انیمیشن؛ شامل لوگو و نام دفتر، نام مشاور، شماره‌های تماس با آیکون تماس، شناسهٔ آگهی و امتیازدهی ۱ تا ۵ به مشاور
- باز شدن پاپ‌آپ «گزارش مشکل» با انیمیشن؛ شامل گزینه‌های دلیل گزارش، توضیحات و دکمهٔ ارسال گزارش
- بسته شدن پاپ‌آپ‌ها با دکمهٔ ضربدر، کلیک روی پردهٔ تاریک یا کلید Escape همراه با قفل اسکرول صفحه
- اندازهٔ متن‌های صفحهٔ جزئیات حداقل ۱۶ پیکسل در دسکتاپ و موبایل است
- آگهی‌های مشابه همان شهر

### پاپ‌آپ آژانس

با کلیک روی هر کارت «املاک برتر تهران»، پاپ‌آپ تمام‌صفحه همان آژانس باز می‌شود و اطلاعات زیر را نمایش می‌دهد:

- لوگوی آژانس
- نام آژانس
- شماره‌های تماس (قابل کلیک با `tel:`)

پاپ‌آپ با GSAP از محل کارت باز و به همان سمت بسته می‌شود و شامل مدیریت فوکوس، بستن با `Escape` و قفل اسکرول است.

## APIهای موجود

| متد | مسیر | توضیح |
|---|---|---|
| `POST` | `/api/auth/send-code` | اعتبارسنجی شماره و ارسال کد تأیید (دمو) |
| `POST` | `/api/auth/verify-code` | بررسی کد، ساخت/یافت کاربر و ثبت کوکی ورود |
| `POST` | `/api/auth/logout` | خروج از حساب |
| `GET` | `/api/locations/provinces` | فهرست ۳۱ استان ایران |
| `GET` | `/api/locations/cities` | شهرهای یک استان یا شهرهای پرطرفدار (`?province=`, `?popular=1`) |
| `GET` | `/api/properties` | فهرست آگهی‌ها با فیلتر، مرتب‌سازی و صفحه‌بندی |
| `GET` | `/api/properties/:id` | دریافت اطلاعات یک ملک و افزایش بازدید |

نمونه بدنه درخواست ورود:

```json
{
  "phone": "09xxxxxxxxx",
  "code": "xxxxx"
}
```

> رابط کاربری ورود فعلاً از منطق دمو در `lib/auth.js` استفاده می‌کند و اتصال کامل به APIهای احراز هویت از مراحل بعدی توسعه است.

## طراحی و انیمیشن

- توکن‌های رنگ، تایپوگرافی و شعاع گوشه‌ها در `app/globals.css` تعریف شده‌اند.
- رنگ اصلی برند: `#CB1B1B`
- فونت Shabnam FD به صورت لوکال بارگذاری می‌شود.
- بخش‌های صفحه با کامپوننت `Reveal` و ترکیب GSAP + ScrollTrigger ظاهر می‌شوند.
- پاپ‌آپ آژانس از تکنیک FLIP برای باز شدن از کارت تا تمام‌صفحه استفاده می‌کند.
- نقشهٔ `/rent` از یک چندضلعی ماسک با حفرهٔ مرز ایران استفاده می‌کند تا فقط خاک ایران دیده شود؛ جزئیات پیاده‌سازی در `components/listings/map/LeafletMap.jsx` است.
- انیمیشن‌های غیرضروری برای کاربرانی که `prefers-reduced-motion` را فعال کرده‌اند، حذف می‌شوند.
- عرض محتوای اصلی در دسکتاپ `80%` و در موبایل تمام عرض با فاصله کناری است.

## مدل‌های داده

مدل‌های MongoDB در پوشه `models` قرار دارند و هر کدام توابع کمکی موردنیاز خود را export می‌کنند:

`User`، `Property`، `Agent`، `Agency`، `Favorite`، `BlogPost`، `Category` و `Inquiry`.

اتصال دیتابیس از طریق `lib/mongodb.js` و با استفاده از `MONGODB_URI` انجام می‌شود.

### داده‌های مکانی

فهرست استان‌ها و شهرهای ایران در `lib/data/iran-locations.json` نگهداری می‌شود و از مجموعهٔ عمومی [list-of-cities-in-Iran](https://github.com/sajaddp/list-of-cities-in-Iran) گرفته شده است. شناسهٔ عددی هر شهر در پارامتر `city` آدرس `/rent` استفاده می‌شود.

مرز ساده‌شدهٔ ایران برای ماسک نقشه در `lib/data/iran.geo.json` قرار دارد و از مجموعهٔ عمومی [world.geo.json](https://github.com/johan/world.geo.json) گرفته شده است.

### داده نمایشی

اگر اتصال MongoDB برقرار نباشد یا مجموعه‌های آگهی خالی باشند، لایهٔ `lib/listings/service.js` به‌صورت خودکار از داده‌های نمایشی `lib/listings/demo.js` استفاده می‌کند تا صفحه‌ها بدون دیتابیس هم قابل بررسی باشند.

## وضعیت فعلی و محدودیت‌ها

این پروژه در حال توسعه است. موارد زیر هنوز تکمیل نشده‌اند:

- احراز هویت واقعی و ارسال پیامک (OTP فعلی دمو است)
- اتصال فرم ورود به APIهای سمت سرور
- مسیرهای CRUD کامل برای املاک، مشاورین، آژانس‌ها، علاقه‌مندی‌ها، بلاگ و دسته‌بندی‌ها
- صفحات خرید (`/buy`)، فهرست املاک (`/properties`)، مشاورین (`/agents`) و اخبار (`/news`)
- شماره‌های تماس آژانس‌ها در صفحه Home Pro داده نمایشی هستند

> آگهی‌های `/rent` و جزئیات `/properties/[id]` از دیتابیس خوانده می‌شوند و در نبود آن به داده نمایشی برمی‌گردند.
